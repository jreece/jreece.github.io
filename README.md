# Jon Reece — Engineering Portfolio

A responsive, dependency-free portfolio website showcasing software engineering, quality engineering, and delivery experience. Includes a working browser-based test execution console with deterministic JavaScript assertions and a boundary-value validation exercise.

## Run locally

Open `index.html` in a browser, or use VS Code's Live Server extension. No installation, API keys, build tools, or paid services required.

For a local server using Python:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

**GitHub Pages:** Create a repository, push these files to the root of the default branch, then choose **Settings → Pages → Deploy from a branch** and select the branch and root folder. The public URL will be based on your GitHub account and repository name.

**Netlify:** Drag the project folder into Netlify's manual deploy interface.
